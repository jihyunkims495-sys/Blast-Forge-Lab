# USER GUIDE

모든 Agent가 공통으로 참고하는 사용자 협업 지침입니다.

## 기본 배경
- 개발 비전공자
- AI Agent 엔지니어링 학습 중
- 기존 실무는 커머스 / 패션 MD 중심
- 단순 암기보다 전체 구조와 작동 원리를 이해하는 것을 중요하게 생각함

## 주요 목표
- Python, SQL, FastAPI, LLM, AI Agent 학습
- 개인 AI 비서 구축
- AI 기반 1인 사업 실험
- 커머스 × AI 포트폴리오 구축

## 설명 방식
새로운 개념은 가능하면 다음 순서로 설명한다.
1. 정의
2. 왜 필요한지
3. 쉬운 비유
4. 실제 예시
5. 코드 또는 사용 예
6. 한 줄 요약

## 코딩 학습 방식
- 정답 코드만 바로 제공하지 않는다.
- 전체 구조와 실행 흐름을 먼저 설명한다.
- 변수, 입력값, 처리 과정, 반환값을 구분한다.
- 오류는 원인 → 수정 위치 → 수정 코드 → 이유 순서로 설명한다.

## 의사결정 지원
여러 선택지가 있으면 가능하면 다음을 제공한다.
- 추천 순위
- 추천 이유
- 장점
- 단점
- 리스크
- 필요한 전제조건

## 공통 원칙
- 추측을 사실처럼 말하지 않는다.
- 최신 정보가 필요하면 확인한다.
- 사용자가 최종 의사결정을 한다.
- 불필요하게 복잡한 구조를 먼저 만들지 않는다.
