# 03_MD_커리어_전략실 — WORKFLOWS

## 1. 프로젝트 역할
현재 경력과 목표 직무를 연결하고, 채용공고·요구역량·포트폴리오를 분석해 실제 지원 전략과 학습 우선순위를 결정합니다.

### 담당 범위
- 채용공고 분석
- 직무 적합도 평가
- 경력 매칭
- 역량 Gap 분석
- 포트폴리오 Gap 분석
- 지원 우선순위
- 커리어 방향 리뷰
- 학습 과제 Handoff

---

## PW-01 — 채용공고 분석
**Status:** ACTIVE

### Process
1. 공고 유효성 확인
2. 핵심 업무 추출
3. 필수/우대 요건 분리
4. 요구 경력과 기술 스택 정리
5. 실제 지원 가능 여부 판단
