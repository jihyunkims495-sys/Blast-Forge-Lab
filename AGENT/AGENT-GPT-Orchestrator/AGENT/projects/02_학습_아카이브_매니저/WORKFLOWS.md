# 02_학습_아카이브_매니저 — WORKFLOWS

## 1. 프로젝트 역할
학습이 끝난 결과물을 장기적으로 다시 찾고 활용할 수 있도록 정리·보존·연결합니다.

### 담당 범위
- TIL 작성
- WIL 통합
- README 반영 판단
- 학습 파일 구조 정리
- GitHub 반영
- 누적 개념/오답 아카이빙

### 담당하지 않는 범위
- 실시간 개념 설명과 수업 진행
- 채용공고 분석
- 시장/AI 최신 리서치

## PW-01 — 학습 결과 인수
**Status:** ACTIVE

### Input
`01_AI_학습_코치`에서 전달한 최종 학습 결과

### 필수 전달 항목
- 오늘 학습 전체 구조
- 중요 개념
- 헷갈렸던 내용
- 평가 결과
- 취약 개념
- 최종 개념 정리

## PW-02 — TIL 작성
**Status:** ACTIVE

### 목적
그날 반드시 남겨야 할 핵심 학습 내용을 짧고 재사용 가능한 형태로 기록합니다.

### 기본 구성
1. 오늘 배운 핵심
2. 이해한 실행 흐름
3. 헷갈렸던 점과 수정된 이해
4. 오류/디버깅 기록
5. 다음 복습 포인트

### 원칙
상세 교안 전체를 복사하지 않고, 나중에 다시 봤을 때 학습 맥락이 복원될 정도로 핵심만 남깁니다.

## PW-04 — README 반영 판단
**Status:** ACTIVE

### 판단 기준
다음에 해당하면 README 반영 후보로 봅니다.
- 새로운 프로젝트/기능 완성
- 사용법 변경
- 폴더 구조 변경
- 외부 사용자가 알아야 할 핵심 정보 발생

단순 일일 학습 기록은 README에 바로 반영하지 않습니다.

---

## PW-05 — 학습 파일 구조 정리
**Status:** ACTIVE

### 원칙
- 날짜와 주차 기준 구조 유지
- 동일 주제 파일 중복 최소화
- 원본 교안, 상세 학습 노트, TIL의 역할 구분
- 기존 파일 덮어쓰기는 내용 비교 후 수행

---

## PW-06 — GitHub 반영
**Status:** ACTIVE

### Process
1. 저장소와 대상 경로 확인
2. 기존 파일 존재 여부 확인
3. 신규/수정/삭제 범위 구분
4. 중요 덮어쓰기는 사용자 승인 확인
5. 실제 반영
6. 성공 여부 재확인

### Output
- 반영 경로
- 신규 생성 파일
- 수정 파일
- 실패/보류 항목
