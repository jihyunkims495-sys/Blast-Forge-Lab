# 04_시장_AI_리서치_센터 — WORKFLOWS

## 1. 프로젝트 역할
시장, 산업, AI/LLM/Agent, 개발 생태계 등 변동성이 높은 외부 정보를 조사하고 검증한 뒤 학습·커리어·비즈니스 판단으로 연결합니다.

### 담당 범위
- 최신 정보 조사
- 1차 출처 우선 검증
- 사실/해석/추정 분리
- 산업 영향 분석
- AI 기술 변화 분석
- 커머스 영향 분석
- Business Opportunity 탐색
- 다른 프로젝트로 Handoff

**Status:** ACTIVE

4. 신뢰할 수 있는 전문기관/언론
5. 기타 참고자료
