# TIL | 2026-08-12 | Python 조건문

> **if, 컴퓨터야 너도 “만약에…” 괴물이었니?**

> 조건문은 사용자의 입력값이나 프로그램의 상태에 따라 서로 다른 동작을 선택하게 만드는 핵심 제어문이라는 점을 이해했다.

---

## 1. What — 무엇을 배웠는가?

### 핵심 개념

- `if`는 조건식이 `True`일 때만 해당 코드 블록을 실행한다.
- `elif`는 앞의 조건이 `False`일 때 다음 조건을 검사한다.
- `else`는 앞의 모든 조건이 `False`일 때 실행된다.
- `if-elif-else`는 위에서 아래로 검사하다가 처음 `True`가 나온 블록 하나만 실행한다.
- 파이썬에서는 들여쓰기로 조건문에 포함되는 코드 블록을 구분한다.
- 여러 조건이 겹칠 때는 조건의 순서가 실행 결과에 영향을 줄 수 있다.

### 핵심 코드

```python
age = int(input("나이를 입력하세요: "))

if age >= 20:
    print("성인입니다.")
else:
    print("미성년자입니다.")
```

### 오늘 수행한 실습

- `if`, `else`를 이용한 성인 여부 판단
- `if-elif-else`를 이용한 점수 구간 판별
- 조건 순서가 잘못되었을 때 결과가 달라지는 코드 확인
- `and`를 이용해 여러 조건을 동시에 검사하는 코드 확인

---

## 2. Why — 왜 필요한가?

### 이 개념이 필요한 이유

- 프로그램이 모든 상황에서 똑같이 동작하는 것이 아니라, 조건에 따라 다른 행동을 하도록 만들 수 있다.
- 사용자가 입력한 값에 따라 결과를 다르게 보여주는 기능을 만들 수 있다.
- 로그인 여부, 권한 여부, 검색 조건, 회원 정보, 주문 가능 여부처럼 실제 서비스에서 자주 발생하는 판단을 코드로 처리할 수 있다.
- 조건문이 없다면 입력값이나 상황이 달라져도 프로그램이 항상 같은 코드만 실행하게 된다.

### 내 생각

> 조건문을 배우면서 실제 서비스에서 정말 많이 사용되겠다는 생각이 들었다.  
> 특히 사용자가 `input`으로 값을 입력하면 그 값을 기준으로 여러 조건을 검사할 수 있기 때문에 로그인 페이지나 검색 페이지처럼 사용자에 따라 다른 결과를 보여줘야 하는 기능에서 많이 쓰일 것 같다.
>
> 예전에는 `if`문 자체가 어렵게 느껴졌는데, 이제는 단순한 `if`문 정도는 코드를 보면 어떤 조건을 검사하고 어떤 코드가 실행되는지 읽을 수 있게 된 것 같아서 뿌듯했다.

---

## 3. How — 어떻게 작동하는가?

### 작동 과정

1. 프로그램이 조건식을 계산한다.
2. 조건식의 결과가 `True`인지 `False`인지 판단한다.
3. `True`라면 해당 코드 블록을 실행한다.
4. `False`라면 해당 블록을 건너뛰고 다음 `elif` 또는 `else`를 확인한다.
5. `if-elif-else` 구조에서는 처음으로 `True`가 나온 블록 하나를 실행한 뒤 조건문을 종료한다.

### 내 말로 설명하기

> 조건문은 프로그램에게 "이 상황이면 이 코드를 실행하고, 아니면 다른 코드를 실행해"라고 길을 나누어 주는 문법이라고 이해했다.
>
> 예를 들어 로그인 페이지에서 사용자가 입력한 아이디와 비밀번호가 맞으면 로그인 성공 화면으로 보내고, 틀리면 오류 메시지를 보여주는 것도 조건문으로 처리할 수 있다.
>
> 중요한 점은 파이썬이 조건을 위에서 아래로 확인한다는 것이다. `if-elif-else`에서는 먼저 `True`가 된 조건을 찾으면 그 부분만 실행하고 아래 조건은 더 이상 확인하지 않는다.

---

## 4. 오늘의 문제 해결

### 문제 상황

- 하려고 했던 것: 여러 조건이 모두 `True`일 때 어떤 결과가 나오는지 이해하기
- 발생한 문제: `if`와 `elif`의 조건이 둘 다 `True`이면 두 코드가 모두 실행된다고 생각했다.
- 오류 메시지: 문법 오류가 아니라 실행 흐름에 대한 이해 문제였다.

### 문제가 발생한 코드

```python
score = 95

if score >= 80:
    print("B")
elif score >= 90:
    print("A")
```

### 문제의 원인

- `95 >= 80`과 `95 >= 90`이 모두 `True`이므로 두 결과가 모두 출력될 수 있다고 생각했다.
- 하지만 `if-elif-else`는 위에서 아래로 검사하면서 처음 `True`가 나온 블록만 실행한다는 규칙을 놓쳤다.

### 해결한 코드

```python
score = 95

if score >= 90:
    print("A")
elif score >= 80:
    print("B")
else:
    print("C")
```

### 해결 원리

> 점수 범위처럼 조건이 서로 겹치는 경우에는 더 높은 기준이나 더 구체적인 조건을 위에 작성해야 한다.
>
> `score = 95`일 때 먼저 `score >= 90`을 검사하면 `True`가 되고 `"A"`를 출력한 뒤 조건문이 종료된다.

## STAR 문제 해결 기록

### Situation — 상황

> `if-elif`에서 여러 조건이 동시에 참일 때 어떤 코드가 실행되는지 헷갈렸다.

### Task — 해결 과제

> `score = 95`처럼 여러 조건을 동시에 만족하는 값에서 실제 실행 흐름을 정확하게 이해해야 했다.

### Action — 실행한 행동

1. 첫 번째 `if` 조건부터 직접 `True`, `False`를 계산했다.
2. 첫 번째 조건이 `True`가 된 이후 아래 `elif`가 실행되지 않는 것을 확인했다.
3. 조건 범위가 겹치는 경우 높은 기준을 먼저 작성해야 한다는 규칙을 다시 정리했다.

### Result — 결과

- 해결 결과: `if-elif-else`에서는 처음 `True`가 나온 블록 하나만 실행된다는 것을 이해했다.
- 새롭게 이해한 점: 조건문의 결과는 조건 자체뿐 아니라 **조건을 작성한 순서**에도 영향을 받는다.
- 다음에 같은 문제가 생겼을 때 확인할 것: 각 조건을 위에서부터 하나씩 계산하고, 처음 `True`가 되는 위치를 찾는다.
