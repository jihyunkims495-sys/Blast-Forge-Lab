# 1. 머신러닝과 과적합

머신러닝은 사람이 모든 규칙을 직접 작성하는 대신, **데이터에서 규칙이나 패턴을 학습하도록 하는 방법**이다.

```text
데이터
↓
패턴 학습
↓
새로운 데이터에 예측
```

과적합(Overfitting)은 모델이 학습 데이터에 지나치게 맞춰져서 새로운 데이터에서는 성능이 떨어지는 상태다.

```text
Train 데이터
→ 성능 매우 좋음

새로운 데이터
→ 성능 하락
```

핵심은 학습 데이터를 외우는 것이 아니라 **새로운 데이터에도 적용되는 일반화 능력**을 갖는 것이다.

# 3. 평균, 분산, 표준편차

## 평균

평균은 데이터가 전체적으로 어느 값을 중심으로 하는지 보여준다.

하지만 평균만으로는 데이터가 평균 근처에 모여 있는지, 넓게 퍼져 있는지는 알 수 없다.

## 분산

분산은 데이터가 평균에서 얼마나 퍼져 있는지를 나타낸다.

평균과의 차이를 그대로 더하면 음수와 양수가 상쇄될 수 있다.

```text
데이터: 2, 4, 6
평균: 4
편차: -2, 0, +2
합계: 0
```

그래서 편차를 제곱한다.

```text
(-2)² + 0² + 2²
= 4 + 0 + 4
```

## 표준편차

분산은 제곱해서 계산하므로 원래 데이터와 단위가 달라진다.
표준편차는 분산에 제곱근을 적용해 **원래 단위로 다시 표현한 퍼짐의 크기**다.

```text
평균
→ 데이터의 중심

분산
→ 평균에서 얼마나 퍼져 있는지

표준편차
→ 그 퍼짐을 원래 단위로 표현
```

복습에서 다음 예시를 해석했다.

```text
평균 구매금액 = 80,000원
표준편차 = 120,000원
```

처음에는 "평균보다 큰 금액을 쓰는 유저가 있다"고 생각했지만, 더 정확한 의미는 다음과 같다.

> 평균 구매금액은 8만 원이지만 유저별 구매금액 차이가 크고, 평균보다 훨씬 적게 또는 훨씬 많이 쓰는 유저들이 함께 존재할 가능성이 있다.

# 4. 모집단 분산과 표본분산

전체 데이터를 대상으로 계산하면 모집단 분산을 구한다.
일부 표본으로 모집단 분산을 추정할 때는 일반적으로 `n`이 아니라 `n - 1`로 나눈다.

```text
n - 1
→ 표본분산이 모집단 분산을 지나치게 작게 추정하는 경향을 보정
```

`n - 1`은 **편향을 줄이기 위한 보정**이고, 제곱근을 취하는 것은 **원래 단위로 돌아오기 위한 과정**이라는 점을 구분해야 한다.

# 5. 결측치 확인

```python
df.isnull().sum()
```

처음에는 "결측치를 확인하고 그 값을 더하는 것"이라고 생각했다.

실제 흐름은 다음과 같다.

```text
isnull()
→ 결측치이면 True
→ 값이 있으면 False

sum()
→ True를 1
→ False를 0으로 계산
→ True 개수를 합산
```

따라서 결측치 값 자체를 더하는 것이 아니라 **결측치 여부인 True의 개수를 세는 코드**다.

# 6. 결측치 처리

결측치는 데이터의 종류와 의미에 따라 처리 방법이 달라진다.

## 숫자형 데이터

```python
df['age'] = df['age'].fillna(df['age'].mean())
```

평균이나 중앙값 등을 사용할 수 있다.

## 범주형 데이터

`embark_town`처럼 `Southampton`, `Cherbourg`, `Queenstown`과 같은 범주형 값은 평균을 계산할 수 없다.

```python
mode_embarked = df['embark_town'].mode()[0]
df['embark_town'] = df['embark_town'].fillna(mode_embarked)
```

복습에서 정리한 이유:

> 숫자값이 아니기 때문에 범주 중 가장 자주 등장하는 값으로 결측치를 채울 수 있다.

단, 범주형이라고 무조건 최빈값을 사용하는 것은 아니며 상황에 따라 `Unknown` 같은 별도 범주가 더 적절할 수 있다.

## ffill / bfill

```python
df['deck'] = df['deck'].ffill()
df['deck'] = df['deck'].bfill()
```

```text
ffill
→ 앞의 값으로 채움

bfill
→ 뒤의 값으로 채움
```

# 7. `df.loc`에서 가장 많이 헷갈렸던 부분

기본 구조:

```python
df.loc[행, 열]
```

```python
df.loc[:, 'deck']
```

처음에는 `:`가 첫 컬럼부터 `deck`까지를 의미한다고 생각했다.

하지만 실제 의미는 다음과 같다.

```text
:
→ 모든 행

'deck'
→ deck 열
```

즉:

```python
df.loc[:, 'deck']
```

은 **모든 행에서 `deck` 컬럼을 선택**한다.

반면:

```python
df.loc['deck']
```

은 `deck`이라는 **행 라벨**을 선택하려는 코드다.

실습 중 다음과 같이 작성해서 데이터에 잘못된 행이 생성되기도 했다.

```python
df.loc['deck'] = df['deck'].ffill()
```

컬럼을 수정할 때는 다음처럼 작성해야 한다.

```python
df['deck'] = df['deck'].ffill()
```

또는:

```python
df.loc[:, 'deck'] = df['deck'].ffill()
```

오늘 기억할 규칙:

```text
df.loc[행, 열]

앞 = 행
뒤 = 열
```

# 8. Duplicate

`duplicate`는 중복 데이터를 의미한다.

```python
df.duplicated()
```

각 행의 중복 여부를 `True / False`로 확인한다.

```python
df.duplicated().sum()
```

중복 행 개수를 확인한다.

```python
df.drop_duplicates()
```

중복 행을 제거할 수 있다.

중복이 많으면 평균, 비율, 모델 학습 결과가 왜곡될 수 있기 때문에 EDA 단계에서 확인해야 한다.

# 11. Figure와 Axes

```python
fig, axes = plt.subplots(1, 3, figsize=(18, 5))
```

이 코드는 그래프 3개를 자동으로 그리는 것이 아니라 **그래프를 그릴 공간 3개를 만든다.**

```text
Figure
→ 전체 도화지

axes[0]
→ 첫 번째 그래프 영역

axes[1]
→ 두 번째 그래프 영역

axes[2]
→ 세 번째 그래프 영역
```

실습에서는 다음 코드만 작성했다.

```python
axes[0].hist(df['age'], bins=20)
```

그래서 첫 번째 그래프만 보이고 두 번째와 세 번째는 빈 공간으로 남아 있었다.

복습에서는 처음에 "캔버스만 그렸으니까?"라고 답했고, 최종적으로는 다음처럼 정리했다.

> 3개의 Axes 자리를 만들었지만 `axes[0]`에만 실제 그래프를 그렸기 때문에 나머지 두 영역이 비어 있었다.
