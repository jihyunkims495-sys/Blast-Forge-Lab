# WIL | WEEK 4 | 2026-08-24 ~ 2026-08-28

> **머신러닝을 ‘데이터를 넣으면 알아서 학습하는 것’에서, 데이터 준비부터 Loss·파라미터 조정·검증까지 이어지는 하나의 학습 흐름으로 보기 시작한 주였다.**

---

## 1. 이번 주 한 줄 회고

### 가장 중요하게 배운 것

> 머신러닝은 개별 함수나 모델 이름을 외우는 것이 아니라 `데이터 확인 → X/y 구성 → 전처리 → 모델 → 예측 → Loss → 파라미터 학습 → 검증`의 흐름을 이해해야 한다는 것.

### 가장 어려웠던 것

> 새로운 용어가 빠르게 늘어나면서 모델, 전처리, 활성화 함수, 손실함수, 규제, 평가 방법을 같은 종류의 개념처럼 섞어 생각하지 않고 각각의 역할과 위치를 구분하는 것이 가장 어려웠다.

### 이번 주를 한 문장으로 정리하면

> 막연하게 알고 있던 머신러닝이 실제로 어떤 단계와 부품들로 움직이는지 처음 구조적으로 보기 시작했다.

---

## 2. 이번 주 학습 흐름

- 학습 범위: EDA와 데이터 정제 → 선형회귀와 경사하강법 → 데이터 분할과 스케일링 → 다중회귀와 Ridge/Lasso 규제 → 로지스틱 회귀와 교차검증 → PyTorch·DNN 기초
- 초반: 모델을 만들기 전에 데이터를 확인하고 정리해야 한다는 점을 배우면서 `head()`, `info()`, `describe()`, 결측치, 중복, 평균·분산·표준편차, 시각화 등 EDA 흐름을 익혔다.
- 중간: `X → 모델 → 예측 → 오차 → Loss → 파라미터 조정` 흐름을 중심으로 선형회귀, `fit()`, StandardScaler, Train/Test 분할, Ridge/Lasso 규제를 연결하기 시작했다.
- 후반: 회귀에서 분류로 넘어가면서 Logit, Sigmoid, Softmax, Cross Entropy, K-Fold를 배웠고, PyTorch와 신경망의 입력층·은닉층·활성화 함수·파라미터·Gradient·Optimizer까지 학습 범위가 확장되었다.
- 이번 주의 가장 큰 변화: 함수와 용어를 하나씩 외우기보다 새로운 개념이 머신러닝 전체 과정에서 **어느 단계에 있고 무엇을 입력받아 무엇을 하는지**를 먼저 확인하는 방식으로 학습 관점이 바뀌었다.

## 3. 이번 주에 이해한 것과 헷갈리는 것

### 이제 이해한 내용

#### 개념 1 — 데이터와 모델 학습은 분리된 단계다

- 이전 생각: 데이터를 모델에 넣으면 머신러닝이 알아서 학습하고 결과를 내는 정도로 생각했다.
- 지금 이해한 내용: 데이터를 먼저 확인·정제하고 Feature `X`와 Target `y`를 구성한 뒤, 전처리와 데이터 분할을 거쳐 모델을 학습하고 별도의 데이터로 평가해야 한다. EDA와 전처리도 모델 학습의 중요한 준비 단계다.

#### 개념 2 — 객체 생성과 `fit()`은 다르다

- 이전 생각: `Ridge()`나 `StandardScaler()`를 만드는 것과 `fit()`을 호출하는 것이 비슷하게 느껴졌다.
- 지금 이해한 내용: `Ridge()`와 `StandardScaler()`는 도구를 생성하는 단계이고, `fit()`은 각 객체가 데이터에서 필요한 값을 학습하는 단계다. 모델은 X와 y의 관계를 학습하고, StandardScaler는 평균과 표준편차를 학습한다.

#### 개념 3 — 머신러닝 용어는 역할별로 분류해야 한다

- 이전 생각: MSE, Ridge, Sigmoid 같은 용어가 모두 모델 학습에 사용되기 때문에 비슷한 종류의 개념처럼 섞였다.
- 지금 이해한 내용: 전처리(Scaling, One-Hot), 모델(Linear/Logistic Regression), 활성화 함수(Sigmoid, Softmax, ReLU), 손실함수(MSE, BCE, CCE, SCCE), 규제(Ridge, Lasso), 검증/평가(Accuracy, K-Fold)는 서로 다른 역할을 가진다.

### 아직 헷갈리는 내용

#### 개념 1 — Loss와 분류 학습 흐름

- 헷갈리는 부분: `Logit → Sigmoid/Softmax → 예측 → Cross Entropy` 흐름과 MSE·BCE·CCE·SCCE를 상황에 따라 구분하는 것이 아직 자동으로 나오지 않는다.
- 다음에 확인할 것: 회귀/이진분류/다중분류 예시를 하나씩 두고 **모델 출력 → 활성화 함수 → 정답 형태 → 손실함수** 순서로 직접 분류한다.

#### 개념 2 — `fit()` / `transform()` / `fit_transform()`과 데이터 누수

- 헷갈리는 부분: 각각의 의미는 설명을 보면 이해하지만 예제 없이 바로 설명하거나 작성하는 것은 아직 어렵다.
- 다음에 확인할 것: Train에는 `fit_transform()`, Test에는 `transform()`을 사용하는 이유를 StandardScaler 예제로 다시 작성하고, Test에 `fit()`하면 왜 Data Leakage인지 설명한다.

#### 개념 3 — 신경망 학습 구조

- 헷갈리는 부분: 입력층·은닉층·뉴런·ReLU·Loss·Backpropagation·Gradient·Optimizer가 각각 무엇인지 배웠지만 전체 학습 루프를 혼자 연결하기는 아직 어렵다.
- 다음에 확인할 것: `Forward → Loss → Backward → Gradient → Optimizer → Parameter Update`를 실제 PyTorch 코드와 한 줄씩 대응시킨다.

## 4. KPT 주간 회고

### Keep - 계속할 것

- 이번 주에 잘한 점: 에러가 발생했을 때 단순히 정답 코드를 받기보다 현재 변수와 DataFrame 구조를 확인하면서 `KeyError`, `NameError`, `AttributeError`, `loc` 사용 오류의 원인을 추적했다.
- 이해하는 데 도움이 된 학습 방법: 코드 한 줄을 외우지 않고 `입력 → 처리 → 결과`, `객체 생성 → fit → 결과 사용` 순서로 읽고, 비슷한 용어를 비교하면서 차이를 확인했다.
- 다음 주에도 유지할 습관: 새로운 개념이 나오면 `어느 단계인가? / 입력은 무엇인가? / 출력은 무엇인가? / 왜 필요한가? / 앞 개념과 어떻게 연결되는가?`를 먼저 확인한다.

### Problem - 개선할 것

- 반복해서 막힌 부분: 현재 객체에 어떤 컬럼이 남아 있는지 추적하는 것, `fit()` 계열 메서드 구분, 손실함수와 규제처럼 서로 다른 레벨의 개념을 구분하는 것.
- 아직 혼자 설명하거나 적용하기 어려운 부분: Logit과 Cross Entropy, Optimizer, Backpropagation, 기울기 소실, ReLU의 비선형성, 전체 신경망 학습 흐름.
- 시간을 비효율적으로 사용한 부분: 이전 실습 코드를 다음 문제에 그대로 가져오면서 문제의 Species·Feature 요구조건을 다시 확인하지 않아 오류를 수정하는 데 시간이 들었다.

### Try - 다음 주에 시도할 것

- 다시 공부할 내용: `Logit → 활성화 함수 → Loss`, `fit/transform/fit_transform`, `Loss → Gradient → Optimizer → Weight Update`.
- 예제를 보지 않고 시도해볼 것: Iris 데이터 필터링 → X/y 분리 → Train/Test 분할 → LogisticRegression 학습 → predict → accuracy 계산까지 기본 분류 코드를 직접 작성한다.
- 새롭게 시도할 학습 방법: 코드를 쓰기 전에 문제를 `입력 X / 정답 y / 모델 / 전처리 / 평가 방법 / 출력`으로 먼저 분해하고 요구조건과 기존 코드가 일치하는지 확인한다.
- 줄이거나 하지 않을 것: 새로운 용어를 역할 구분 없이 단어 자체로 외우거나, 이전 실습 코드를 요구사항 확인 없이 그대로 복사해서 사용하는 습관을 줄인다.
